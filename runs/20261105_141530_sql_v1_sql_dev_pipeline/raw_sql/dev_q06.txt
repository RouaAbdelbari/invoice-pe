Pour répondre à la question "Quel est le montant HT moyen par facture (arrondi à 3 décimales) ?", vous pouvez utiliser la requête SQL suivante :

```sql
SELECT 
    ROUND(AVG(net_amount), 3) AS average_net_amount
FROM 
    fact_invoice;
```

Cette requête calcule la moyenne du montant HT (`net_amount`) pour toutes les factures validées et arrondit le résultat à 3 décimales.

Si vous voulez voir le montant HT moyen par fournisseur, vous pouvez ajouter un `GROUP BY` sur la table `dim_supplier` :

```sql
SELECT 
    s.supplier_name,
    ROUND(AVG(fi.net_amount), 3) AS average_net_amount
FROM 
    fact_invoice fi
JOIN 
    dim_supplier s ON fi.supplier_id = s.supplier_id
GROUP BY 
    s.supplier_name;
```

Cette requête affichera le nom du fournisseur et le montant HT moyen par fournisseur, arrondi à 3 décimales.
