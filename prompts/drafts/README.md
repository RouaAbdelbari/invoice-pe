# Dossier prompts/drafts/

Brouillons de prompts proposés par l'assistant. 
**Jamais utilisés dans une exécution sans validation explicite de l'étudiant.**

Pour utiliser un brouillon :
1. L'étudiant le relit, le modifie si besoin, valide le contenu.
2. Il le copie dans `prompts/` sous un nom versionné (`extraction_v1.txt`, etc.).
3. Il crée l'entrée correspondante dans `prompts/CHANGELOG.md`.
4. Seulement alors, `extract.py --prompt extraction_v1` peut être lancé.
